    전광판 관리

    구글 시트
    위에서부터 순서대로 돌아가며 나옵니다. ▲▼ 로 순서를 바꾸면 바로 저장되고, 전광판에는 20~30초 안에 반영됩니다.
    순서미리보기내용화면기간표시사용
    불러오는 중…
    전광판에 등록할 주소
    ViPlex Express의 '웹 페이지' 위젯에 아래 주소를 한 번만 넣으면 됩니다. 주소의 키가 틀리면 전광판은 검은 화면이 됩니다.
    화면해상도플레이어 IP전광판 주소
    불러오는 중…
    '전광판 API' 프로젝트에 넣을 시트 ID
    이미지는 '전광판 이미지' 드라이브 폴더에 원본과 화면 크기에 맞춘 사진이 함께 저장됩니다.
    ViPlex Express 설정 방법
    1. ViPlex Express에서 해당 플레이어(현관 10.10.10.12 / 대강당 10.10.10.11)에 접속
    2. 새 솔루션(프로그램) 만들기 → 화면 크기는 전광판 해상도 그대로 (현관 1152×160, 대강당 2304×256)
    3. 위젯 중 웹 페이지를 추가 → 주소에 위 '전광판 주소' 붙여넣기
    4. 위젯 위치 X 0, Y 0, 크기는 화면과 같게 (현관 1152×160, 대강당 2304×256), 재생 시간은 길게(또는 반복)
    5. 게시(전송) → 이후 내용은 이 업무포털에서만 바꾸면 됩니다
