# 어르신 배움터 접수 시스템

학기마다 코드를 고치지 않도록 학기 정보를 **학기목록** 탭에 모아 둔 구조입니다.

## 파일
- `Code.gs` — 서버 로직 (접수, 조회, 취소, 학기 읽기)
- `index.html` — 신청 화면
- `check.html` — 신청 내역 및 결과 조회 화면
- `appsscript.json` — 앱스크립트 설정
- `navbar.html`, `resultView.html` — **이 폴더에 없습니다.** 앱스크립트 프로젝트에 있는 파일을 그대로 두세요. `index.html`, `check.html`이 `include()`로 불러서 없으면 화면이 깨집니다.

## 학기목록 탭
REGISTRY_ID 스프레드시트(현재는 2026 하반기 강좌정보 스프레드시트)에 `학기목록` 탭을 만들고 아래 열을 둡니다.

| 학기ID | 학기명 | 신청시트ID | 강좌정보시트ID | 신청탭 | 강좌탭 | 참여자탭 | 사용 |
|---|---|---|---|---|---|---|---|
| 2026H2 | 2026년 하반기 어르신 배움터 | 1u8MrJeVfzCli_wyt-m8-G07uTYDoEkyxDkKvMmc1VTY | 1_mRID4mwFypGU8pSFMZcwf35NDqjpTLuUUoe2a-mPvc | Form Responses 1 | 2026년하반기어르신배움터강좌정보 | 2026년하반기노인일자리참여자 | Y |

- **사용 = Y** 인 학기는 `?term=`을 생략했을 때 열리는 기본 학기입니다. 한 번에 하나만 Y로 두세요.
- 신청탭은 비우면 `Form Responses 1`, 참여자탭은 비우면 `노인일자리참여자`를 씁니다.
- 학기별 **환경설정** 탭(A2 접수 시작, B2 마감, C2 결과 발표, D2 웹앱 주소)과 **중복제한강좌** 탭은 강좌정보 스프레드시트 안에 있어야 합니다.

## 새 학기 (예: 2027 상반기)
1. 기존 2026 하반기 강좌정보 스프레드시트를 복사합니다. 탭 이름(강좌탭, 참여자탭)을 2027 기준으로 바꾸고 강좌·참여자 데이터를 입력합니다.
2. 신청 시트를 새로 만듭니다. 첫 행 헤더는 기존 신청 시트와 같아야 합니다(성명, 생년월일, 성별, 연락처, 면제 사유, 요일별 열, 타임스탬프 등).
3. 학기목록 탭에 새 행을 추가하고 `사용`을 Y로 바꾸면 기본 학기가 바뀝니다. 이전 학기는 N으로 두면 됩니다.
4. 이전 학기 접수 링크(`?term=2026H2`)는 계속 열립니다.

## 배포
Apps Script에서 **배포 → 배포 관리 → 새 버전**으로 같은 웹앱을 다시 배포합니다. 웹앱 주소가 바뀌지 않도록 기존 배포를 수정하세요.

## 규칙
- 연락처는 `010-0000-0000` 형식만 받습니다. 조회·취소는 이름, 생년월일, 연락처가 모두 맞아야 합니다.
- 취소는 접수 마감 전에만 가능합니다.
