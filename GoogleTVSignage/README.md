# 구글 TV 사이니지 앱 (WebView 래퍼)

구글 TV에서 사이니지 웹페이지를 전체 화면으로 띄우는 안드로이드 TV 앱입니다.
크롬 브라우저 대신 안드로이드 WebView를 쓰므로 TV 하드웨어 디코딩을 사용합니다.

## 1. 사이니지 주소 넣기

`app/build.gradle.kts` 의 `SIGNAGE_URL` 값을 사이니지 GAS 웹앱 주소로 바꿉니다.

```kotlin
buildConfigField("String", "SIGNAGE_URL", "\"https://script.google.com/macros/s/배포ID/exec\"")
```

- 반드시 `https` 주소를 쓰세요. 영상 주소도 `https`여야 합니다 (http는 차단됨).
- 사이니지 모드 주소(예: 접수대용 `?mode=desk`)를 넣으면 그 화면이 뜹니다.

## 2. 빌드

1. Android Studio를 설치하고 이 `GoogleTVSignage` 폴더를 엽니다.
2. 처음 열면 Gradle 동기화가 자동으로 돕니다 (인터넷 필요).
3. 메뉴 **Build > Build APK(s)** 를 누르면 `app/build/outputs/apk/debug/app-debug.apk` 가 만들어집니다.

## 3. 구글 TV에 설치 (사이드로드)

1. 구글 TV에서 **설정 > 시스템 > 정보**로 가서 **빌드 번호**를 7번 눌러 개발자 모드를 켭니다.
2. **설정 > 시스템 > 개발자 옵션**에서 **USB 디버깅**(또는 네트워크 디버깅)을 켭니다.
3. 같은 네트워크에서 PC의 ADB로 연결합니다.
   ```
   adb connect TV의_IP주소:5555
   adb install -r app-debug.apk
   ```
4. TV 런처에 **거제시종합사회복지관 사이니지**가 나타나면 실행하고, 자동 시작은 `BootReceiver`가 처리합니다.

## 4. 동작 설명

- 화면 꺼짐 방지, 리모컨 뒤로가기 무시 (앱이 닫히지 않음)
- 영상 소리 포함 자동 재생 (사용자 클릭 불필요)
- 네트워크가 없거나 페이지를 못 열면 안내 문구를 띄우고 10초마다 다시 시도
- 전원을 켜면 자동으로 실행

## 5. 확인이 필요한 점

- 자동 실행(부팅 시 실행)은 구글 TV 버전에 따라 정책이 다를 수 있습니다. 재부팅 후 실행되는지 직접 확인해 주세요.
- 구글 계정 로그인이 필요한 GAS 페이지라면 WebView에서 로그인 화면이 뜰 수 있습니다. 사이니지 페이지는 보통 공개로 배포하므로 문제가 없어야 합니다.
- 이 프로젝트는 빌드 환경이 없는 상태에서 작성했습니다. 처음 빌드할 때 오류가 나면 메시지를 알려 주세요.
