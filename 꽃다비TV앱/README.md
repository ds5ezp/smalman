# 꽃다비 카페 사이니지 안드로이드 TV 앱

꽃다비 카페 사이니지 웹페이지를 구글 TV(안드로이드 TV)에서 전체 화면으로 띄우는 앱입니다.
구글 TV 사이니지 앱(`구글TV사이니지/`)과 같은 구조이며, 별도 앱으로 설치되어 둘이 서로 간섭하지 않습니다.

## 동작
- 전체 화면, 화면 꺼짐 방지
- 영상 소리 포함 자동 재생 (클릭 없이)
- 리모컨 뒤로가기로 앱이 닫히지 않음
- 웹뷰가 죽거나 네트워크가 끊기면 10초마다 다시 불러옴
- 전원을 켜면 자동 실행
- 운영시간 밖의 절전 화면과 정지 동작은 웹페이지(`꽃다비카페사이니지/`)가 처리함

## 1. 웹앱 주소 넣기
`app/build.gradle.kts`의 `SIGNAGE_URL`을 꽃다비 카페 사이니지 GAS 배포 주소로 바꿉니다.

```kotlin
buildConfigField("String", "SIGNAGE_URL", "\"https://script.google.com/macros/s/배포ID/exec\"")
```

## 2. 빌드
1. Android Studio에서 이 `꽃다비TV앱` 폴더를 엽니다.
2. Gradle 동기화가 끝나면 **Build > Build APK(s)** 를 누릅니다.
3. `app/build/outputs/apk/debug/app-debug.apk` 가 만들어집니다.

## 3. 설치 (사이드로드)
구글 TV 사이니지 앱 README의 3번과 같습니다. 개발자 모드와 USB/네트워크 디버깅을 켠 뒤 다음을 실행합니다.

```
adb connect TV의_IP주소:5555
adb install -r app-debug.apk
```

## 4. 확인할 점
- TV 설정에서 화면 보호기(대기 화면)와 자동 절전이 **꺼져** 있는지 확인하세요. 앱이 켜져 있어도 TV 시스템 설정이 화면을 끄면 꺼질 수 있습니다.
- 재부팅 후 자동 실행이 되는지 한 번 확인하세요.
- 꽃다비 사진 폴더는 **링크가 있는 모든 사용자 - 뷰어**로 공유되어 있어야 TV에서도 사진이 보입니다.
