# 만족도 조사 화면 (업무포털 연동)

터치 사이니지에서 참석자가 스티커를 손가락으로 끌어 **그렇다 / 아니다** 칸에 붙이는 스티커 설문입니다.
조사 내용(제목·질문·칸 이름·붙일 때 문구·소리)은 **업무포털 > 홍보관리 > 만족도 조사**에서 입력하고,
조사마다 생기는 **전용 주소**를 행사장 노트북에서 열면 그 조사 화면만 나옵니다.

| 파일 | 역할 |
|---|---|
| `Code.gs` | 조사 화면 백엔드. `웹 앱 주소?s=키` 로 조사를 찾아 보여 주고, 붙인 스티커를 시트에 저장 |
| `Survey.html` | 조사 화면. Apps Script 편집기에서 파일 이름이 `Survey` 여야 함 |

업무포털(대시보드)과 이 프로젝트는 같은 구글 시트(`만족도 조사 (업무포털)`)를 함께 씁니다.

- **조사** 탭: 키, 이름, 템플릿, 상태, 설정, 회차, 만든사람, 만든일시, 수정일시
- **응답** 탭: 키, 회차, 칸, 스티커, x, y, 회전, 시각, 응답ID

## 처음 설정 (한 번만)

1. 업무포털 > 만족도 조사 > **처음 설정** 탭에서 시트 ID를 복사합니다. (업무포털이 시트를 자동으로 만듭니다)
2. 업무포털과 **같은 구글 계정**으로 script.google.com 에서 새 프로젝트 '만족도 조사 화면'을 만듭니다.
3. `Code.gs` 를 붙여 넣고 맨 위 `SHEET_ID = ''` 따옴표 안에 1번 시트 ID를 넣습니다.
4. **+ → HTML** 로 `Survey` 파일을 만들고 `Survey.html` 내용을 붙여 넣습니다.
5. **배포 → 새 배포 → 웹 앱**: 실행 사용자 **나**, 액세스 권한 **모든 사용자** → 권한 승인.
6. 나온 웹 앱 주소(…/exec)를 업무포털 처음 설정 탭 3번에 붙여 넣고 저장합니다.

코드를 고친 뒤에는 **배포 관리 → 수정 → 새 버전**으로 배포해야 주소가 그대로 유지됩니다.

### 보안

- '모든 사용자'여야 행사장 노트북이 로그인 없이 열 수 있습니다.
- 조사마다 무작위 키(`?s=q…`)가 붙어, 주소를 아는 사람만 그 조사를 엽니다.
- 이 주소로는 스티커 붙이기만 됩니다. 문구 수정·리셋·결과·삭제는 업무포털(복지관 계정)에서만 됩니다.
- 업무포털에서 조사를 **종료**하거나 **삭제**하면 그 주소로는 더 이상 스티커를 붙일 수 없습니다.

## 업무포털에서 하는 일

- **새 조사 만들기**: 템플릿(축제·감사) 고르기 → 제목·질문·칸 이름·붙일 때 문구(그렇다/아니다 각각)·기관명·소리 입력
  - 질문에서 `*별표*` 로 감싼 말은 색으로 강조, 줄바꿈은 그대로
  - 붙일 때 문구는 한 줄에 하나. 문구 안에서 줄을 바꾸려면 ` / `
- **전용 주소 복사 / 미리보기**(결과에 저장 안 됨) / **노트북 실행 파일** 받기
- **결과·엑셀**: 현재 회차 개수와 비율, 붙인 순서, 회차별 합계, CSV 받기
- **더보기**: 마지막 스티커 1개 취소, 리셋(회차를 올려 화면을 비움, 이전 결과는 시트에 남음), 조사 종료/다시 진행, 복사해서 새 조사, 삭제

문구를 고치거나 리셋·종료하면 행사장 화면에 **20초 안에** 반영됩니다 (새로고침 필요 없음).

## 행사장 노트북

1. 업무포털에서 받은 **노트북 실행 파일(.bat)** 을 더블클릭 → 엣지(없으면 크롬)가 전체 화면으로 열립니다. 끝낼 때 `Alt + F4`.
   - 엣지 + 인터넷이면 음성이 사람처럼 자연스러운 AI 목소리(선희·인준)로 나옵니다.
   - 처음부터 배경 음악이 나오도록 자동재생을 허용해 엽니다.
2. 사이니지의 **HDMI 선과 USB 터치 선**을 모두 노트북에 꽂고, `윈도우키 + P` → **두 번째 화면만**, 디스플레이 방향 **세로**.
3. 화면 맨 아래 기관명을 **3초 길게 누르면** 관리자 메뉴: 저장 상태, 터치 위치 확인, 소리 시험, 소리·숫자 표시 잠깐 켜고 끄기.

### 인터넷

- 행사장에 인터넷이 있어야 합니다. **처음 화면을 열 때는 꼭** 연결되어 있어야 합니다.
- 중간에 끊겨도 스티커는 정상으로 붙고, 노트북에 보관했다가 다시 연결되면 시트로 보냅니다.
  화면 오른쪽 아래에 `저장됨` / `보내는 중` / `연결 끊김 · 보낼 스티커 N개 보관 중` 이 표시됩니다.
- 인터넷이 전혀 없는 행사장은 저장소의 `교육문화축제-만족도조사` 폴더(파일 하나로 동작하는 버전)를 쓰세요.

## 템플릿 추가하는 법

1. `Survey.html`
   - `TEMPLATE_FIXED` 에 새 이름 추가 (예: `spring: {}`)
   - CSS에 `.tpl-spring …` 으로 디자인 추가 (색 변수 `--green`, `--orange` 등을 바꾸면 칸·안내 색이 함께 바뀜)
   - 머리 장식이 따로 필요하면 `<header>` 안에 넣고 `spring-only` 같은 클래스로 보이고 숨기기
2. 업무포털 `Index.html` 의 `SURVEY_TEMPLATES` 에 같은 이름으로 이름·설명·쓰는 제목 칸(`fields`)·기본 문구(`defaults`) 추가
3. 업무포털 `Code.gs` 의 `SURVEY.TEMPLATES` 와 이 폴더 화면에 같은 이름이 있어야 저장됩니다.
