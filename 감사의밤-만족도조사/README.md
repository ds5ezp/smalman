# 감사의 밤 만족도 조사 (터치 사이니지용)

가로형 터치 사이니지에서 참석자가 스티커를 손가락으로 끌어 **Yes / No** 칸에 붙이는 스티커 설문입니다.
여러 사람이 동시에 끌어도 됩니다 (손가락 최대 10개).

## 실행

- `index.html` 파일 하나로 동작합니다. 사이니지의 크롬(또는 엣지)에서 열고 전체 화면(F11)으로 띄우세요.
- 인터넷이 없어도 동작합니다. (인터넷이 있으면 귀여운 글꼴을, 없으면 기본 글꼴을 씁니다)
- 같은 폴더에 `logo.png` 를 넣으면 아래쪽 기관명 옆에 로고가 나옵니다.

## 사용법

- 아래 받침의 스티커를 꾹 눌러 끌어다 Yes 또는 No 칸에 놓으면 붙고, 칸 밖에 놓으면 사라집니다.
- 붙은 스티커는 브라우저에 자동 저장되어 새로 고침하거나 전원이 꺼져도 남아 있습니다.

## 관리자 메뉴

하단 **기관명을 3초 동안 길게 누르면** 열립니다 (키보드가 있으면 `Ctrl+Shift+A`).

- 현재 결과 (개수·비율)
- 결과 파일 저장: 엑셀에서 열리는 CSV (응답별 시각 포함)
- 마지막 스티커 1개 취소 / 전체 초기화 (두 번 눌러야 지워짐)
- 화면에 숫자 표시 켜기·끄기

## 행사마다 바꾸기

`index.html` 의 `CONFIG` 부분에서 제목, 질문, 스티커 종류, 기관명 등을 바꿀 수 있습니다.
다른 행사에 다시 쓸 때는 `storageKey` 도 바꾸면 이전 결과와 섞이지 않습니다.
