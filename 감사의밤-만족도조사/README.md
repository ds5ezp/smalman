# 감사의 밤 만족도 조사 (터치 사이니지용)

터치 사이니지에서 참석자가 스티커를 손가락으로 끌어 **Yes / No** 칸에 붙이는 스티커 설문입니다.
여러 사람이 동시에 끌어도 됩니다 (손가락 최대 10개).

## 실행

- `index.html` 파일 하나로 동작합니다. 사이니지의 크롬(또는 엣지)에서 열고 전체 화면(F11)으로 띄우세요.
- **세로형(1080×1920)·가로형 화면 모두 지원**합니다. 화면 방향을 보고 배치가 자동으로 바뀝니다.
  세로로 세운 모니터가 옆으로 누운 화면으로 나오면 윈도우 [설정 → 디스플레이 → 디스플레이 방향]을 '세로'로 바꾸세요.
- 인터넷이 없어도 동작합니다. (인터넷이 있으면 귀여운 글꼴을, 없으면 기본 글꼴을 씁니다)
- 같은 폴더에 `logo.png` 를 넣으면 아래쪽 기관명 옆에 로고가 나옵니다.

## 사용법

- 아래 받침의 스티커를 꾹 눌러 끌어다 Yes 또는 No 칸에 놓으면 붙고, 칸 밖에 놓으면 사라집니다.
- 붙은 스티커는 브라우저에 자동 저장되어 새로 고침하거나 전원이 꺼져도 남아 있습니다.

## 관리자 메뉴

하단 **기관명을 3초 동안 길게 누르면** 열립니다 (키보드가 있으면 `Ctrl+Shift+A`).

- 현재 결과 (개수·비율)
- 결과 파일 저장: 엑셀에서 열리는 CSV (응답별 시각 포함)
- 마지막 스티커 1개 취소 / 전체 초기화 (두 번 눌러야 지워짐)
- 화면에 숫자 표시 켜기·끄기

## 행사마다 바꾸기

`index.html` 의 `CONFIG` 부분에서 제목, 질문, 스티커 종류, 기관명 등을 바꿀 수 있습니다.
다른 행사에 다시 쓸 때는 `storageKey` 도 바꾸면 이전 결과와 섞이지 않습니다.

## 라즈베리파이에서 쓰기

### 1. 실행 파일로 띄우기

이 폴더를 라즈베리파이에 통째로 복사한 뒤, 터미널에서 실행합니다.

```bash
bash 라즈베리파이-실행.sh
```

크로미움을 전체 화면(키오스크)으로 띄우면서 다음을 함께 처리합니다.

- `--touch-events=enabled` : 크로미움이 터치 화면을 못 알아보는 경우에도 터치로 받게 함
- 두 손가락 확대, 옆으로 밀어 뒤로 가기 막기
- (X11 화면일 때) 화면 꺼짐 방지, 터치 방향을 모니터에 자동으로 맞춤

종료는 키보드 `Alt+F4` 입니다. 이미 켜져 있던 크로미움은 실행할 때 닫힙니다.

### 2. 터치가 안 될 때: '터치 위치 확인'

관리자 메뉴(기관명 3초 길게 누르기, 또는 마우스로 길게 클릭) → **터치 위치 확인**.
노란 십자를 손가락으로 눌러 봅니다.

| 결과 | 원인 | 해결 |
|---|---|---|
| 누른 곳에 초록 점 | 정상 | — |
| 점이 엉뚱한 곳에 찍힘 | 화면만 세로로 돌리고 터치는 가로 그대로 | 아래 3번 |
| 아무 점도 안 찍힘 | 크로미움이 터치를 못 받음 | 1번 실행 파일로 띄우기 |
| 빨간 점(마우스)만 찍힘 | 터치가 마우스로 들어옴 | 1번 실행 파일로 띄우기 (안 되면 한 손가락씩만 동작) |

### 3. 터치 방향을 화면 회전에 맞추기

먼저 터미널에서 `echo $XDG_SESSION_TYPE` 으로 화면 방식을 확인합니다.

- **wayland** (최신 라즈베리파이 OS Bookworm 기본)
  - 메뉴 → 기본 설정 → **Screen Configuration** → 모니터 그림을 오른쪽 클릭 → **Touchscreen** 에서 터치 장치를 선택하고 적용.
    이렇게 하면 터치가 그 모니터의 회전을 따라갑니다.
- **x11** (예전 OS 또는 X11로 바꾼 경우)
  - 실행 파일이 자동으로 맞춰 줍니다. 직접 하려면:
    ```bash
    xinput list                                  # 터치 장치 이름 확인
    xinput map-to-output "터치장치이름" HDMI-1    # 화면 이름은 xrandr 로 확인
    ```
