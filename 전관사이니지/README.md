# 전관 사이니지

거제시종합사회복지관 전관 스마트 사이니지 (Google Apps Script 웹앱)

## 파일

| 파일 | 역할 |
|---|---|
| `Code.gs` | 백엔드. 시트·드라이브·캘린더·날씨·뉴스 데이터를 모아 화면에 전달 |
| `index.html` | 디스플레이 화면. Apps Script 편집기에서는 파일명이 `index`로 등록되어야 함 |

## 최초 설정

1. Apps Script 편집기 → **프로젝트 설정 → 스크립트 속성**에 추가
   - `OPENWEATHER_KEY` : OpenWeather API 키 (코드에 키를 적지 않음)
2. 편집기에서 `setupHomepageFeedSheets` 를 한 번 실행 (`홈페이지RSS`, `홈페이지행사` 탭 생성, 권한 승인)
3. **트리거** → 함수 `autoSyncWelfareNews`, 시간 기반, 1시간마다 (언론보도 자동 수집)
4. **배포 → 새 배포 → 웹앱**
   - 실행 사용자: 나
   - 액세스 권한: 모든 사용자 (또는 복지관 도메인)
   - 발급된 URL을 디스플레이 2대의 브라우저에서 전체 화면으로 열기

## 갱신 주기

| 항목 | 주기 | 설정 위치 |
|---|---|---|
| 공지·일정·날씨·뉴스·기관방문 | 1분 (`index.html` `DASHBOARD_REFRESH_MS`) | 화면 코드 |
| 상단 슬라이드(드라이브·행사) | 5분 (`index.html` `SLIDE_REFRESH_MS`) | 화면 코드 |
| 날씨·미세먼지 | 10분 캐시 (`CACHE_SEC_WEATHER`) | `Code.gs` |
| 실시간 뉴스 | 15분 캐시 (`CACHE_SEC_NEWS`) | `Code.gs` |
| 오늘의 일정 | 5분 캐시 (`CACHE_SEC_SCHEDULE`) | `Code.gs` |

캐시 덕분에 디스플레이를 늘려도 날씨·뉴스 API 호출 수는 늘지 않습니다.

## 변경 이력 (1단계)

- 상단 '언론 보도 소식' 슬라이드 제외 (하단 '복지관 언론보도' 패널만 사용)
- 행사 사진의 base64 변환 제거 → 이미지 프록시 주소 사용 (호출 수·응답 크기 감소)
- 날씨·뉴스·일정 CacheService 캐시 적용
- API 키를 스크립트 속성으로 이동
- 실시간 뉴스가 5건 미만일 때 같은 기사가 반복되던 문제 수정
- Tailwind v2 → v3 교체 (v3 클래스가 적용되지 않던 문제 수정)
- 캘린더 장소·시간 등 외부 문자열을 `innerHTML` 대신 텍스트로 출력
