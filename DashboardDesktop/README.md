# 복지관 통합 대시보드 - 윈도우 프로그램

대시보드 웹 주소를 전체 화면 프로그램으로 여는 윈도우 앱입니다.
구글 로그인은 이 프로그램 안에 저장되므로, 한 번 로그인하면 계속 유지되고 크롬의 계정이나 시크릿 창과 섞이지 않습니다.

## 기능
- 설정(Ctrl+,)에서 **대시보드 주소**를 넣고 저장
- 전체 화면 (F11), 새로고침 (F5), 글자 크기 조절
- 구글 로그인 유지
- 인터넷이 끊기면 안내 화면을 보여 주고 10초마다 자동 재시도
- 윈도우 시작 시 자동 실행 (설정에서 켜고 끌 수 있음)
- 설치 파일(.exe)로 만들어 바탕화면 아이콘과 시작 메뉴에 등록

## 1. 빌드 준비 (윈도우 PC에서 한 번만)
1. [Node.js LTS](https://nodejs.org/)를 설치합니다.
2. 이 `DashboardDesktop` 폴더에서 명령 프롬프트(또는 PowerShell)를 열고 다음을 실행합니다.
   ```
   npm install
   ```

## 2. 설치 파일 만들기
```
npm run dist
```
완료되면 `dist` 폴더에 `복지관 통합 대시보드 Setup 1.0.0.exe`가 만들어집니다. 이 파일을 실행하면 설치됩니다.

## 3. 실행해 보기 (설치 없이)
```
npm start
```

## 4. 처음 사용할 때
1. 프로그램을 실행하면 설정 창이 열립니다.
2. 대시보드 주소(`https://script.google.com/macros/s/…/exec`)를 넣고 저장합니다.
3. 구글 계정으로 로그인합니다. 복지관 계정을 선택하세요.

## 참고
- 설치 파일은 인증서 서명이 없어서 처음 설치할 때 "알 수 없는 게시자" 경고가 나올 수 있습니다. **추가 정보 > 실행**을 누르면 됩니다.
- 구글이 프로그램 안 로그인을 막으면 알려 주세요. 로그인만 기본 브라우저에서 하도록 바꿀 수 있습니다.
- 자동 업데이트는 아직 넣지 않았습니다. 새 버전을 만들면 설치 파일을 다시 설치하면 됩니다.
