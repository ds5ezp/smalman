# 제14회 교육문화축제 만족도 조사 (세로형 터치 사이니지용)

세로로 세운 터치 사이니지(1080×1920)에서 참석자가 스티커를 손가락으로 끌어 **그렇다 / 아니다** 칸에 붙이는 스티커 설문입니다.
여러 사람이 동시에 끌어도 됩니다 (손가락 최대 10개). 가로 화면에서도 자동으로 배치가 바뀌어 동작합니다.

## 실행

- `index.html` 파일 하나로 동작합니다. 크롬(또는 엣지)에서 열고 전체 화면(F11)으로 띄우세요.
- 인터넷이 없어도 동작합니다. (인터넷이 있으면 귀여운 글꼴을, 없으면 기본 글꼴을 씁니다)
- 같은 폴더에 `logo.png` 를 넣으면 아래쪽 기관명 옆에 로고가 나옵니다.
- 감사의 밤 조사와 결과가 따로 저장되어 섞이지 않습니다.

## 사용법

- 아래 받침의 스티커를 꾹 눌러 끌어다 칸에 놓으면 붙고, 칸 밖에 놓으면 사라집니다.
- 스티커가 많아지면 모두 함께 조금씩 작아지고, 이미 붙은 곳에 놓으면 옆 빈자리로 비켜 붙습니다 (200개 이상도 칸 안에 들어감).
- 붙은 스티커는 브라우저에 자동 저장되어 새로 고침하거나 전원이 꺼져도 남아 있습니다.

## 움직임과 사용법 자동 안내

- 제목 글자가 차례로 통통 튀고, 색종이가 떨어지고, 스티커와 이름표가 살랑살랑 움직입니다.
- 스티커를 붙이면 축하 조각이 톡톡 터집니다.
- **15초 동안 아무도 만지지 않으면** 손가락 그림이 나타나 사용법을 보여줍니다.
  ① 스티커를 꾹 누르고 → ② 그렇다/아니다 칸으로 끌어서 → ③ 손을 떼면 붙는 모습을 설명과 함께 반복합니다.
  누군가 화면을 만지면 바로 멈추고, 안내용 스티커는 결과에 들어가지 않습니다.
- 기다리는 시간은 `CONFIG` 의 `idleSec` 으로 바꿉니다 (`0` 이면 안내를 끔).

## 관리자 메뉴

하단 **기관명을 3초 동안 길게 누르면** 열립니다 (키보드가 있으면 `Ctrl+Shift+A`).

- 현재 결과 (개수·비율)
- 결과 파일 저장: 엑셀에서 열리는 CSV (응답별 시각 포함)
- 마지막 스티커 1개 취소 / 전체 초기화 (두 번 눌러야 지워짐)
- 화면에 숫자 표시 켜기·끄기
- 터치 위치 확인

## 문구 바꾸기

`index.html` 의 `CONFIG` 부분에서 회차, 제목, 질문, 칸 이름, 기관명 등을 바꿀 수 있습니다.

스티커를 붙인 뒤 잠깐 뜨는 문구는 칸마다 따로 정합니다. 목록 중 하나가 무작위로 나옵니다.

```js
thanksYes: [               // '그렇다'에 붙였을 때
  '참여해 주셔서 감사합니다! 💛',
  ...
],
thanksNo: [                // '아니다'에 붙였을 때
  '소중한 의견 감사합니다.\n다음엔 더 좋게 준비할게요! 🌱',
  ...
],
```

- 줄을 추가하거나 지워도 됩니다. 각 문구는 따옴표 `'...'` 로 감싸고, 끝에 쉼표 `,` 를 붙입니다 (마지막 줄은 쉼표 없어도 됨).
- 문구 안에 `\n` 을 넣으면 그 자리에서 줄이 바뀝니다. 긴 문구는 자동으로 조금 더 오래 보입니다.
다른 행사에 다시 쓸 때는 `storageKey` 도 바꾸면 이전 결과와 섞이지 않습니다.

## 노트북에 연결해서 쓰기

1. **선 두 개 연결**: 사이니지의 HDMI 선(화면)과 **USB 터치 선**(터치)을 모두 노트북에 꽂습니다. HDMI만 꽂으면 화면은 나오지만 터치가 안 됩니다.
2. **화면 표시**: `윈도우키 + P` → **두 번째 화면만**.
3. **세로 화면**: 설정 → 시스템 → 디스플레이 → 디스플레이 방향 **세로**.
4. **띄우기**: `index.html` 을 크롬으로 열고 `F11` (전체 화면).
5. **꺼짐 방지**: 설정 → 전원에서 화면 끄기·절전 **안 함**. 덮개를 닫아 둘 거라면 제어판 → 전원 옵션 → '덮개를 닫으면' **아무것도 안 함**. 충전기 연결.
6. **확인**: 관리자 메뉴 → **터치 위치 확인** 에서 누른 곳에 초록 점이 찍히는지 보고, 테스트로 붙인 스티커는 **전체 초기화**.

터치하면 노트북 화면 쪽이 반응하면: 2번처럼 '두 번째 화면만' 으로 바꾸거나, 시작 메뉴에서 **태블릿 PC 설정** → **설정** 을 눌러 사이니지 화면을 터치해 맞춥니다.

결과는 그 노트북의 크롬에 저장되므로, 행사 중에는 같은 노트북·같은 브라우저로 끝까지 진행하세요.
